A one-line roast of a smart fridge that refuses to open after midnight, entered in the
[Midnight Fridge Roast bounty on make.fun](https://make.fun/c/u-carbon-forge-midnight-fridge-roast-fc5d44a7).

Run it with Node 22 or later:

```sh
node main.ts
```

It writes the entry line to `/output/entry.txt`.
